Install on Chrome, Brave & Edge in 3 Steps

No Chrome Web Store needed. Since FillHarbor is 100% open-source, you can load it in less than 30 seconds for free.

01

Download Extension ZIP

Get the latest production-ready package directly from GitHub.

Download ZIP (Unpack it)
02

Open Chrome Extensions

In Chrome (or Brave/Edge), open a new tab and paste this address:

chrome://extensions

Toggle Developer mode in the top-right corner to ON.

03

Click "Load unpacked"

Click the Load unpacked button on the top-left, and select the unzipped fillharbor-main folder.

✓ Done! Pin the anchor icon to toolbar.
