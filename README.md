## ⚡ Highlights

- **Universal Form Engine**: Works on Google Forms and standard HTML5 survey forms.
- **9 Realistic Personas**: Medical, Student, Academic, Tech, Consumer, Corporate, Balanced, Agreeable, and Critical.
- **7 Localized Territories**: Culturally accurate names, cities, emails, and institutions (India, US, UK, Canada, Australia, Germany, Global).
- **Likert Rating Variance**: Generates realistic rating distributions based on persona personality profiles instead of flat random answers.
- **Multi-Section Automation**: Automatically navigates through multi-page forms, handles "Next" buttons, and submits.
- **100% Client-Side Privacy**: Zero analytics, no tracking, and no external servers.


## 🚀 Installation

### Mozilla Firefox (One-Click)
Install directly from the official store:  
👉 **[Add to Firefox (Mozilla AMO)](https://addons.mozilla.org/en-US/firefox/addon/fillharbor-bulk-form-filler/)**

### Google Chrome, Brave & Edge (Free 1-Click Install)

1. **[Download Extension ZIP](https://github.com/pankajsagvekar/fillharbor/archive/refs/heads/main.zip)** and extract it.
2. Open Chrome and navigate to `chrome://extensions`.
3. Turn **ON** the **Developer mode** toggle in the top-right corner.
4. Click **Load unpacked** (top-left) and select the extracted `fillharbor-main` folder.


## 🛠️ Usage

1. Open your Google Form in Chrome or Firefox.
2. Click the **FillHarbor** anchor icon in the browser toolbar.
3. Choose your **Origin Region** and **Respondent Persona**.
4. Set the number of **Responses** and desired **Pace** (Fast ~1s, Normal ~2s, Safe ~4s).
5. Click **Fill Once** to preview, or **Auto Submit** to start bulk submissions.


## 🔒 Permissions & Privacy

FillHarbor requires only two scoped permissions:
- `activeTab`: To inspect and fill questions in the active form tab.
- `storage`: To save your persona and region preferences across sessions.
- Host Access (`https://docs.google.com/forms/*`): Restricted exclusively to Google Forms.

*FillHarbor collects zero user data, zero telemetry, and makes zero external API network requests.*
